# Karina Taylor — Professional Portfolio

Version 1 static portfolio for GitHub Pages.

## Stack
- HTML
- CSS
- minimal JavaScript
- SVG
- WebP image assets
- no framework
- no build process
- no paid dependencies

## Pages
- Home
- About
- Projects
- Résumé / Contact
- CIN case study
- Institutional Visibility case study

## Before publishing
1. Replace GitHub/LinkedIn/email placeholders.
2. Add the final résumé PDF to `assets/documents/`.
3. Update the résumé page with the real PDF link.
4. Review all pages on desktop and mobile.

## Local preview
Open `index.html` in any browser.
